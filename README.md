# PaperPreview

**把层层文件夹里的论文，变成一目了然的本地论文架。**

PaperPreview 是一个面向 Windows 的本地论文浏览工具。选择已有的论文文件夹，就可以在浏览器中按目录查看封面、搜索论文、预览 PDF，并打开配套解读。适合已经习惯用文件夹保存论文、希望更方便查找和阅读的人。

论文仍保存在您自己的目录中。程序只监听本机 `127.0.0.1`，浏览和预览不需要上传文件，也不需要账号。

## 能做什么

- **沿用文件夹结构**：递归读取子目录，默认折叠文件夹树，支持年份筛选。
- **快速找论文**：搜索标题、文件名或文件夹，按阅读状态、文件类型和时间筛选，切换封面或列表视图。
- **直接阅读**：单击预览首页、全文或文件信息；双击在新标签页打开原文。
- **标记已阅**：将 `HaveRead` 等已阅目录显示为标签；标记或取消已阅时，移动 PDF 到对应位置。
- **复制 PDF**：把真实文件复制到 Windows 剪贴板，方便粘贴到资源管理器或支持文件粘贴的应用。
- **打开配套解读**：另外设置解读目录，匹配到原文和解读后才显示「打开解读」。
- **按需整理**：新 PDF 直接放在论文根目录，点击「刷新 / 整理」后按首次整理时的修改日期归入季度；跨年时归入年度文件夹。

后台刷新只读取变化。整理和已阅操作会实际移动文件，由您点击对应按钮触发；同名文件不会覆盖。您也可以继续手动管理全部文件。

## 快速开始

### 1. 下载并解压

点击本仓库的 **Code → Download ZIP**，把整个压缩包解压到一个固定文件夹。保留 `wheels/` 等随附文件，无需把程序放进论文目录。

### 2. 准备 Python

需要 **Windows x64 和 64 位 Python 3.11 或更新版本**。如果尚未安装，可从 [Python 官网](https://www.python.org/downloads/windows/) 安装，并启用 Python Launcher 或「Add Python to PATH」。

首次启动会在程序目录创建 `.venv`，从随附的离线安装包安装 PDF 组件；依赖安装和日常运行均使用这个独立环境。

### 3. 启动

双击 **`启动论文浏览器.cmd`**。浏览器会自动打开本地页面，默认地址为 `http://127.0.0.1:8873/`，端口被占用时会尝试后续端口。

启动时还会在程序目录生成带图标的 **`打开论文预览.lnk`**，以后可以使用这个快捷方式。移动程序目录后，请先运行一次 `.cmd` 重新生成快捷方式；换电脑后应重新创建 `.venv`。

### 4. 设置目录

点击页面的「目录设置」，分别填写或选择：

| 路径 | 用途 |
| --- | --- |
| 论文目录 | 您现有的论文文件夹，设置后开始读取 |
| 解读目录 | 可选，存放原文 PDF 和配套解读文件 |

两个路径初始为空，需要手动设置。设置保存在本机，下次启动自动读取。

## 两个常用场景

### 新加入一篇论文

把 PDF 放到论文目录根目录，点击「刷新 / 整理」。例如首次整理时修改日期是 2026 年 11 月，会进入 `2026-10-12/`。这里的 `10-12` 表示 10—12 月。

到了 2027 年，2026 年的季度目录会在整理时归入 `2026-01-12/`。已在子目录中的文件保留原分类，之后修改 PDF 也不会自动改变归档季度。

### 给论文配上解读

解读目录中需要同时保存原文和解读，原文文件名与论文库中的一致。例如：

```text
论文目录/
└─ 2026-10-12/
   └─ SigLIP 2.pdf

解读目录/
├─ SigLIP 2.pdf
└─ SigLIP 2_论文深度解读.pdf
```

支持「论文解读」「论文深度解读」「阅读笔记」等后缀，也支持明确的论文简称；有多个候选原文时不会猜测关联。解读目录只读，不参与归档。

## 仓库内容

```text
PaperPreview/
├─ 启动论文浏览器.cmd      # 双击启动
├─ start.ps1               # 初始化独立环境、创建快捷方式并启动服务
├─ server.py               # 本地服务
├─ 论文资料浏览器.html     # 浏览界面
├─ PaperPreview.ico        # 快捷方式图标
├─ requirements.txt        # Python 依赖版本
├─ wheels/                 # Windows x64 离线安装包
├─ library_config.example.json
├─ 使用说明.md             # 完整操作说明与常见问题
└─ THIRD_PARTY_NOTICES.md   # 随附组件说明
```

运行后产生的 `.venv/`、快捷方式、目录设置、归档记录及日志均保留在本机，由 `.gitignore` 排除。仓库不包含个人论文、解读文件或个人目录索引。

更多操作说明见 [使用说明](使用说明.md)。启动失败时可查看程序目录中的 `startup-error.log`。
